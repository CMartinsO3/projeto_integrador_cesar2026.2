🩸 HemoFlow
Guia de Transporte

Função na Cloudflare Workers que recebe uma requisição do HemoFlow e devolve a guia de transporte das bolsas de sangue.

Ruan Carlos Oliveira da Silva · rcos3@cesar.school

Onde a função entra

Do pedido do hospital até a guia na mão do motorista

Hospitalpede hemocomponente
(tipo, quantidade, prazo)
→
Backend HemoFlowaloca bolsas (FEFO)
calcula rota (Dijkstra)
→
Função HTTPPOST /guia-transporte
valida e emite a guia
→
GuiaJSON para o sistema
HTML para imprimir

Função stateless: tudo o que ela precisa vem no corpo da requisição. Não acessa banco de dados.

Regras verificadas antes de emitir

A guia só sai “apta” se tudo estiver certo

Compatibilidade ABO/Rhmesma matriz 8×8 do backend Java
FEFObolsas listadas da validade mais próxima para a mais distante
Validade na entregaa bolsa precisa estar válida na chegada prevista
Cadeia friatempo de rota ≤ limite do componente (plaquetas: 90 min)
Janela de entregachegada prevista dentro do prazo do hospital
Quantidadenº de bolsas igual ao que foi pedido

// resposta

  "pendencias": [], "cadeiaFria": { "temperaturaExigida": "2 °C a 6 °C", ... },
  "transporte": {...}, "itens": [...], "checklist": [...] }
201guia apta para transporte
422guia bloqueada + pendências
400JSON ou campos inválidos
Demonstração

Rodando a função

  • Testes unitários com node:test (8 testes)
  • Runtime local da Cloudflare com wrangler dev
  • Guia apta → 201 · guia bloqueada → 422 com as pendências
  • Guia imprimível com ?formato=html
  • Deploy: npx wrangler login + npm run deploy → URL pública *.workers.dev
Resumo

Obrigado!
