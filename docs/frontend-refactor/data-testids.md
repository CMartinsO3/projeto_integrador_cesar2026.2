## Convencoes

- Prefixo por modulo e elemento em kebab-case.
- Linhas dinamicas usam id de negocio: `modulo-linha-{id}`.
- Formularios, submits e filtros levam o mesmo prefixo.
- Alertas usam o prefixo do modulo.
